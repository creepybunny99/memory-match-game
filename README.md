# Memory Match

A clean, self-contained **Memory Match** card game in a single `index.html` — no build step, no dependencies. Open the file in any browser and play.

## How to play
Flip two cards per turn. If the symbols match, they stay face-up; if not, they flip back. Clear the whole board in as few moves as you can.

## Features
- Three difficulty presets: **Easy (4×3)**, **Classic (4×4)**, **Hard (6×4)**
- Live **moves** and **timer**
- Per-difficulty **best score** saved in `localStorage`
- Emoji symbol set, shuffled every deal
- No-animation dark bento UI, procedural monochromatic palette

## Run it
Just open `index.html` in a browser. That's it.
